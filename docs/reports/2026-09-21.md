## Decisions taken

- ADR-0001: SQLite knowledge store, with entity inheritance and a generic edge
  table.
- ADR-0002: one uvicorn process serves the API and the SPA.
- ADR-0003: agents propose changesets, and `kb/apply.py` is the only writer.
- ADR-0004: the SRS is the source of requirement text, and issue bodies are
  generated from it.
- ADR-0005: Actions that receive a token are pinned by commit digest.
- ADR-0006: SQLAlchemy Core + Alembic, with no ORM session. The choice is
  built for a schema expected to be reshaped several times.
- ADR-0007: Material-native Mermaid. The docs build makes no network calls.
- ADR-0008: M0 closes on evidenced requirements. Unevidenced NFRs move to M1.
- Not an ADR: the Semgrep plugin was dropped (a reversible editor-tooling
  toggle).
