## 1. Duplication — WATCH

- **Medium** `src/cvforge/kb/apply.py:115-144` `_write_transaction` and
  `src/cvforge/kb/embeddings.py:136-157` `_write_transaction` are the same function,
  body and docstring (pylint R0801). Both open a connection, issue `BEGIN IMMEDIATE`,
  roll back on any `BaseException`, and commit. *Remediation:* keep one canonical copy in
  `kb/db.py` (it already owns `make_engine`) and import it in both modules. The transaction
  discipline is the property most likely to be fixed in one copy and forgotten in the other.
- **Low** `_now()` is defined twice: `src/cvforge/kb/apply.py:110` and
  `src/cvforge/llm/settings_store.py:51`. Fold into the same shared place.
- Carried from the previous report: `.claude/hooks` shared `main()` tail and the two inline
  `python3 -c` payload parsers are unchanged (Low).
- Resolved from the previous report: the hand-written TS `Health` mirror. `frontend/package.json:13`
  now generates `src/api/schema.d.ts` from `tests/golden/snapshots/openapi.json` (`make ui-gen`).

## 5. Architectural drift — HEALTHY

`kb/`, `llm/` and `ingest/` now exist, so the boundaries were checked by grepping imports.

- `llm/` must not import `kb.apply`: **no violation.** `llm/` imports `kb.vocab`, `kb.models`,
  `kb.schema`, `kb.embeddings`, `kb.queries` only (`llm/tools.py:13-16`, `llm/convert.py:12`,

- `api/` must not bypass `kb/`: **no violation.** `api/knowledge.py`, `proposals.py`,

- `kb/queries.py` must not write: **no violation.** No insert/update/delete/commit/`add`/driver
  SQL in the file; it only does `conn.execute(select ...)`.
- Invariant 2 (writes only in `kb/apply.py`): writes outside it are `llm/settings_store.py`
  (`app_setting`) and `kb/embeddings.py` (`entity_vec` derived index). Both are in
  `REGISTERED_WRITERS` in `tests/unit/test_write_path_invariant.py:48-50`, matching ADR-0011 and
  ADR-0013, and neither touches entity, edge or assertion rows. `ingest/extract.py:19` imports
  `kb.apply` (the sanctioned write path) and `llm.agents`, which is the expected direction.
- Informational: `ingest/` and `llm/` are coupled in both directions of convenience only
