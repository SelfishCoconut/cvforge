# C1 Frontend (chat, review, knowledge, settings) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the M1 backend operable in the browser: chat with the assistant, review its proposals, browse stored knowledge with provenance, configure the provider.

**Architecture:** A React SPA that is a pure client of `/api`. Types are generated from the committed OpenAPI snapshot so the UI cannot silently disagree with the API. Server state lives in TanStack Query; routing in React Router; accessibility primitives from Radix. Nothing in the UI mutates knowledge except by calling the existing review/commit endpoints.

**Tech Stack:** React 19, TypeScript (strict), Vite, Tailwind v4, React Router, TanStack Query, Radix UI, `openapi-typescript`, Vitest + Testing Library. Backend additions: FastAPI (PR0, SPA fallback).

**Spec:** `docs/superpowers/specs/2026-10-05-c1-frontend-design.md` (parent plan: `docs/superpowers/plans/2026-09-26-m1b-agent-layer.md`, package C1).

## Global Constraints

- Frontend gate: `npm run lint`, `typecheck`, `build`, `test:coverage` with **90% lines/branches/functions/statements** (`vite.config.ts`). Run from `frontend/`.
- Backend gate (PR0 and Task 1): `make check`-equivalent — ruff, `mypy --strict` over `src tests scripts`, xenon max-absolute C, pytest with 90% line+branch. Google docstrings on public API.
- Evidence excerpts, entity text and chat replies are **untrusted**: text nodes only; `dangerouslySetInnerHTML` is banned by lint.
- No UI path requests, stores or renders an API key value (ADR-0012); `api_key_env` is a variable *name*.
- Colour is never the only carrier of meaning (every classification badge has its text).
- No shadcn/ui. Tooltip primitive is dropped (nothing needs it); tabs and drawer/dialog/switch are created in the task that first uses them.
- Closed vocabulary: classifications `new|known|duplicate|conflict`; op statuses `pending|accepted|edited|rejected|applied`; proposal statuses `open|committed`; never invent values.
- Every PR: open the issue first (`gh issue create`, label `req:FR-xx`/`infra` + milestone), branch `feat/...`, body contains `Closes #<n>` and "How to validate", Conventional Commits, trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`, squash merge after required CI is green. Update `docs/roadmap.md` in the same PR whenever milestone state changes.
- Tests are synthetic; no live model calls.

## Review Focus

1. **Stream ends without `done`** (server crash, proxy cut) → chat must show an error, not a silently truncated reply that looks complete. Test in Task 3 and Task 6.
2. **Deep link reload** (`/review/3` pressed F5 on the real server) → must serve the SPA, not 404; unknown `/api/...` must still 404 as JSON. Task 1.
3. **Review decisions race / stale view**: a 409 on commit or review (proposal already committed in another tab) → show the server's reason and refetch, never a stale enabled Commit. Task 8.
4. **Hostile text** in excerpts/names (`<img onerror>`, `javascript:` URLs, very long unbroken strings) → rendered inert, layout does not break. Tasks 8, 10.
5. **Empty and failing lists** (no proposals, no entities, 404 entity, API down) → explicit empty/error states, not blank screens. Tasks 8, 10.

  ```ts
  import type { ChatEvent } from "./types";
  export class StreamError extends Error {}

  export async function* readNdjson<T>(response: Response): AsyncIterable<T> {
    if (!response.body) throw new StreamError("response has no body");
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = "";
    const parse = (line: string): T => {
      try { return JSON.parse(line) as T; }
      catch { throw new StreamError("stream contained a malformed line"); }
    };
    try {
      for (;;) {
        const { done, value } = await reader.read();
        if (done) break;
        buffer += decoder.decode(value, { stream: true });
        let nl = buffer.indexOf("\n");
        while (nl !== -1) {
          const line = buffer.slice(0, nl).trim();
          buffer = buffer.slice(nl + 1);
          if (line) yield parse(line);
          nl = buffer.indexOf("\n");
        }
      }
      buffer += decoder.decode();
      const rest = buffer.trim();
      if (rest) yield parse(rest);   // cut mid-object -> StreamError from parse
    } finally {
      reader.releaseLock();
    }
  }

  export async function* readChatEvents(response: Response): AsyncIterable<ChatEvent> {
    for await (const event of readNdjson<ChatEvent>(response)) {
      if (event.type === "error") throw new StreamError(event.message);
      yield event;
      if (event.type === "done") return;
    }
    throw new StreamError("the stream ended before the reply was complete");
  }
  ```
  Note: `return` inside `readChatEvents` triggers the inner generator's `finally`, releasing the lock.
